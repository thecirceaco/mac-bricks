# MAC Bricks Agent Notes

## Scope

These instructions apply to the entire `mac-bricks` repository.

## Repo Role

`MAC Bricks` is the Bricks child theme product.

- Read `.codex/README.md` before making non-trivial changes.
- Use [`thecirceaco/mac`](https://github.com/thecirceaco/mac) as the source of truth for shared governance, repo-boundary rules, and the local `.codex` model.
- Keep repo-local context focused on Bricks child-theme implementation and product-local docs.
- Do not redefine MAC product governance here.

## Editing Discipline

Before editing, check `git status` and preserve user changes.

- keep repo-local context under `.codex/context/`
- keep repo-local skills under `.codex/skills/<skill-name>/SKILL.md`
- publish public product docs or changelog entries through `mac-docs` only when the visible product story changes
