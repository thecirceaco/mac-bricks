Company standard Bricks child theme for WordPress projects.

== Changelog ==

= 1.1.0 =
* The asset helpers only work with readable .css files inside the theme's assets/ folder.
* Stylesheet handles are reduced to a-z, 0-9 and dashes, and a stylesheet's own handle is left out of its dependencies.
* mac_bricks_asset_url() returns an escaped URL.
* The helpers accept missing or wrongly typed arguments and return an empty value instead of stopping the page.
* Tested with WordPress 7.1.

* Initial release
