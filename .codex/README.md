# MAC Bricks Codex Context

This directory stores repo-local Codex context for `mac-bricks`.

Shared MAC governance lives in [`thecirceaco/mac`](https://github.com/thecirceaco/mac). This repo should keep only Bricks child-theme implementation context, product-local notes, and operational skills.

## Rules

- Keep repo-specific context under `.codex/context/`.
- Keep repo-specific skills under `.codex/skills/<skill-name>/SKILL.md`.
- Do not copy shared governance from `mac`.
- Update `mac-docs` only when the public product documentation or changelog needs to change.
